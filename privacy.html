Privacy Policy

Effective 14 September 2026

Who we are

Nocta Frequencies operates the YouTube channel @noctafrequencies and the internal software "Nocta Sleep Factory" (the "API Client").

What the API Client does

The API Client is a command-line program that runs on a single computer owned by the channel operator. It uses the YouTube Data API v3 to (1) upload videos produced by the operator to the operator's own channel, (2) set video titles, descriptions, tags and thumbnails, (3) create and manage the operator's own playlists, and (4) read the operator's own channel and playlist information. It uses YouTube API Services and is subject to the YouTube API Services Terms of Service.

Users of the API Client

The API Client has exactly one user: the channel operator. It is not distributed, sold, or made available to anyone else. No member of the public signs in to it.

Data we access and store

Through Google OAuth 2.0 the operator grants the API Client the scopes youtube.upload and youtube. The API Client stores, only on the operator's computer: an OAuth refresh token for the operator's own Google account; the IDs, titles and playlist membership of videos it uploaded; and rendering metadata for those videos. It does not access, collect, store or process any data about viewers, subscribers, commenters or any other YouTube user. It does not read comments, analytics, or personal information of anyone.

Google user data

The only Google user data handled is the operator's own authorization token and the operator's own channel content. This data is never shared with, sold to, or transferred to any third party. It is not used for advertising. It is stored on the operator's local disk with file permissions restricted to the operator.

Social platform integrations

The same single-operator tool posts announcements of our own new videos to accounts that we own on other platforms: Pinterest, Telegram, Bluesky, X, Facebook and Instagram. For each platform it stores only an access token or app password for our own account, on the operator's computer, and it sends only content we created: the video title, our own thumbnail image, a short description and a link to our own YouTube video. It does not read, collect, store or process data about any other user of those platforms, it does not read followers, comments, boards, feeds or messages, and it never shares data between platforms or with any third party. Each integration is optional and inactive until the operator adds that platform's credential file.

Cookies and tracking

This website sets no cookies and uses no analytics or tracking. YouTube's own privacy policy governs the YouTube channel: policies.google.com/privacy.

Data retention and deletion

The operator can delete the stored token and metadata at any time by deleting the local files. Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately stops the API Client from working.

Contact

Questions about this policy: contact the channel through the "About" tab at youtube.com/@noctafrequencies/about.

Changes

We will post any changes to this policy on this page with a new effective date.
